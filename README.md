# 두근두근 도키도키 인외 오피스♡

웹에서 바로 돌아가는 연애 시뮬레이션. 원작 시나리오: 「돌격! 우당탕탕 인외 오피스!」

## 실행
`index.html`을 브라우저로 열면 됩니다. (또는 이 폴더에서 `python3 -m http.server` 후 http://localhost:8000)

## 에셋
`assets/` 폴더의 md(배경 리스트 · CG 리스트 · 캐릭터 행동 리스트)를 기준으로 `assets/manifest.js`에 연결돼 있습니다.

- 새 그림을 만들면 `manifest.js`에서 해당 항목의 `null`을 파일 경로로 바꾸면 됩니다.
  - 배경이 `null`이면 지정한 대체 배경을 보여 줍니다.
  - CG가 `null`이면 CG 없이 스탠딩 그림으로 진행합니다.
- 캐릭터 그림의 흰 배경은 게임이 불러올 때 자동으로 투명하게 지웁니다. 원본 파일은 바뀌지 않습니다.
- 대사에서 포즈 지정: `호치키스[당황2]: …….` (포즈 이름 = `manifest.js`의 `poses` 키)
- 정수기·시계·용지·마우스는 아직 그림이 없어서 임시 SVG(`assets/char/*.svg`)를 씁니다.

## 시나리오 수정
`js/story.js` 맨 위에 문법 설명이 있습니다. 대사는 `호치키스[blush]: 안 빨개졌습니다.` 형식입니다.

## 파일
- `js/engine.js` 게임 진행·선택지·호감도·루트 판정·엔딩·저장
- `js/audio.js` 배경음악/효과음 (코드로 합성, 파일 없음)
- `css/style.css` 화면 디자인
