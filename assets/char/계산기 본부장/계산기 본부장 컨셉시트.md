## 2. 형태 원칙

- **사람 얼굴 없음.** 머리 = 데스크 계산기 통째, 목 아래 = 인간 남성의 몸.
- 머리 방향: 세로로 세우되 **윗부분이 뒤로 약 30° 젖혀진 원근** (책상 위 계산기처럼). 윗변이 좁고 세로가 짧아 보이며, 아래 앞쪽 두께 면이 살짝 보임. **평면 회전(갸웃) 아님.** 화면이 살짝 위를 향해 내려다보는 여유.

![[ref/계산기-원근-콜라주.png|260]]
- 머리 크기: 폭은 사람 머리 폭, 높이는 사람 머리의 약 1.3배까지. 어깨보다 확실히 좁게.
- 목 연결: 계산기 하단(`0` `00` 줄 아래 블랙 테두리)이 셔츠 칼라 위에 바로 얹힘. 목 피부 노출 없음.
- 감정 = **LCD 표시 + 손 연기.**

## 3. 머리 — 데스크 계산기

![[ref/계산기-머리-정면.png|200]] ![[ref/계산기-머리-측면.png|300]]

> 형태·각도는 오른쪽(3/4), **키 배색은 왼쪽**(블루 메모리키 + 레드 AC). 오른쪽은 무채색이라 포인트가 없음.

| 부위 | 디자인 역할 |
|---|---|
| **LCD 화면** (7세그먼트 숫자) | 감정 표시 장치. 사실상 "얼굴" |
| **블랙 상단 하우징 + 태양광 패널** | 머리 윗부분 실루엣. 태양광 패널은 이마 위치 |
| **실버 키 패널** | 머리 몸통. 정장의 블랙과 대비 |
| **블루 메모리키 (MC MR M- M+)** | 컬러 포인트 1 → 사원증 줄 색으로 연결 |
| **레드 AC 키** | 컬러 포인트 2 → 감정 리셋 버튼 (아래 표정 참고) |

## 4. 의상 — 완전 정석 쓰리피스

![[ref/계산기-의상-쓰리피스.webp|200]] ![[ref/계산기-의상-조끼.png|220]] ![[ref/계산기-의상-재킷걸침.webp|170]]

- **다크 차콜 네이비 쓰리피스** — 어둡고 채도 낮은 네이비. 쨍한 네이비·미디엄 그레이·밝은 그레이시 네이비 폐기
- 재킷: 투버튼, **단추 잠금**. 조끼: 단추 끝까지 잠금
- **화이트 드레스 셔츠**, 칼라 빳빳하게
- **넥타이: 다크 버건디(저채도 와인) 솔리드**, 노트는 칼라 가운데 반듯하게, 조끼 안으로 들어감. 비비드 블루 넥타이 폐기
- **메탈 손목시계** — 시간·숫자에 철저한 사람
- 사원증 줄: **블루** (메모리키 색) — 선택사항
- 블랙 옥스퍼드 구두
- 흐트러짐 금지: 소매 걷기, 넥타이 풀기, 단추 풀기 전부 X (기본 차분 기준)

**호치키스와의 구분**
| | 호치키스 대리 | 계산기 본부장 |
|---|---|---|
| 정장 | 차콜 2피스, 재킷 열어 입음 | 미드나잇 네이비 쓰리피스, 전부 잠금 |
| 이너 | 노타이 (니트 or 셔츠) | 화이트 셔츠 + 넥타이 + 조끼 |
| 인상 | 모던 실무자, 거리감 | 정통 포멀, 어른의 여유 |

## 5. 포즈 & 표정 차분

| 차분 | LCD | 손 / 몸 | 쓰는 장면 |
|---|---|---|---|
| **기본** | `0.` | 한 손은 주머니, 다른 손으로 **시계 찬 손목의 소매(커프스)를 정리**. 손은 허리 높이 — 머리에서 멀리. (깍지 자세는 손이 머리를 가리고 어색해서 폐기) | "여주 씨." |
| **업무 / 검토** | 숫자가 계속 바뀜 | 서류를 한 손으로 넘겨봄, 화면은 서류 쪽 | "3페이지 수치가 잘못됐어요." |
| **무심한 다정** | 화면이 잠깐 꺼짐 → 켜짐 | **재킷을 벗어 팔에 걸침** (조끼 차림) | "밥부터 먹어요." · 야근/퇴근 장면 |
| **당황** | `E` (에러) | 자기 머리의 **AC 키를 손가락으로 누름** (리셋 시도) | 여주의 기습 플러팅 |
| **질투 / 독점욕** | `99999999` 꽉 참 | 넥타이 노트를 조여 고침 | 호치키스·복사기가 여주에게 접근 |
| **순정** (개인 루트) | 화면이 은은히 밝아짐 → `1004` | 시계를 풀어 손에 쥠 (시간 계산 포기) | 고백 |

> **정석 → 흐트러짐**이 감정 곡선. 공략이 진행될수록 재킷 벗음 → 넥타이 만짐 → 시계 풀기 순으로 한 겹씩 풀린다.

**화면 크롭**
- 스탠딩: 머리~허벅지 중간
- 대사창 얼굴창: **LCD 화면 클로즈업** — 표시만 바꿔 끼움. 7세그먼트라 도트로 그리기 쉬움

  1px dark outlines, slight jaggies, no anti-aliasing. Do NOT copy these characters.

Head:
- Calculator head is about the width of a normal human head, clearly NARROWER than the shoulders.
