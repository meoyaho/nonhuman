## 2. 형태 원칙

- **사람 얼굴 없음.** 머리 = 스테이플러 통째, 목 아래 = 인간 남성의 몸.
- 감정은 사람 표정이 아니라 **스테이플러 동작(윗판 개폐·심·딸깍)** + **손 연기**로 표현.
- 머리 크기: **스테이플러 높이 = 사람 머리 높이.** 길이는 어깨너비보다 약간 짧게. 전신은 약 7.5~8등신 (아래 비율 시안 기준).
- 머리 자세: **수평으로 반듯하게** 칼라 위에 얹힘. 앞으로 숙이거나 어깨 앞으로 튀어나오지 않게. 살짝 3/4 측면.
- 목 연결: 피부 목·턱 노출 없이 **셔츠 칼라 바로 위에 받침판**.

**비율 기준 시안** · 오른쪽은 제미나이 1차(머리 과대, 목 노출 → 폐기)

## 3. 머리 — 화이트 사무용 스테이플러

![[ref/호치키스-머리.png|500]]

| 부위 | 디자인 역할 |
|---|---|
| **하얀 윗판** (둥근 직사각형, 앞쪽이 살짝 낮은 사선) | 실루엣의 주인공. 고개 숙인 듯한 무뚝뚝한 인상 |
| **크롬 매거진** (윗판 아래 은색) | 감정 노출 부위. 열릴수록 크게 드러남 |
| **뒤쪽 경첩 핀** (은색 점) | 유일한 "눈" 역할 하이라이트. 시선 집중점 |
| **앞쪽 금속 받침판** (꽃 문양) | 시그니처 마크. 타이핀·사원증에 재사용 |
| **바닥 네이비 띠** | 정장 네이비와 연결되는 색 |

## 4. 의상 — 차콜 수트 + 블랙 이너, 노타이

![[ref/호치키스-이너.png|240]] ![[ref/호치키스-핏.png|240]]

> 왼쪽 = **이너 구성**(재킷 안에 블랙 니트, 노타이) · 오른쪽 = **어깨·핏**(넓고 각진 어깨, 길게 떨어지는 재킷). 오른쪽의 넥타이는 제외.
> 폐기: 네이비 + 연하늘 셔츠 조합(v3) — 공무원/영업사원 느낌, 매력 없음.

- **다크 차콜 2버튼 수트**, 단추는 풀어 입음. 어깨는 넓고 각지게, 재킷은 엉덩이를 덮는 길이로 여유 있게 떨어짐
- **블랙 모크넥(하이넥) 니트** — 노타이. 하얀 스테이플러 머리와 최대 대비 → 머리가 가장 잘 뜸
- 니트 소매가 재킷 소매 밖으로 살짝
- **사원증 목걸이: 블랙 얇은 줄, 작은 카드** — 존재감 최소. **홀더 클립 = 스테이플 심(ㄷ자) 모양** ← 핵심 사물 모티프
- 가슴 주머니 볼펜 → **삭제** (핏을 지저분하게 만듦)
- 블랙 레이스업 구두
- 계산기 본부장과 구분: 본부장은 셔츠 + 넥타이 + 쓰리피스의 정통 포멀. 호치키스는 노타이 니트의 모던 실무자.

## 5. 포즈 & 표정 차분

| 차분 | 스테이플러 | 손 / 몸 | 쓰는 장면 |
|---|---|---|---|
| **기본** (냉미남+서툶) | 윗판 닫힘, 크롬은 가는 선. 머리 앞부분이 살짝 옆으로 돌아감(시선 회피) | 한쪽 다리에 체중, 한 손 주머니, 다른 손은 얇은 블랙 파일을 옆으로 느슨히 듦. 여유 있지만 정면을 안 봄 | "네." 단답 |
| **말하기** | 윗판 살짝 들림, 크롬 반쯤 | 양손바닥을 펼쳐 설명하는 제스처 (핏 레퍼런스 포즈) | 업무 설명 — 이때만 말이 길어짐 |
| **당황 / 설렘** | 윗판 덜컥 열림, 크롬 확 노출 + 심 하나 툭 | 주머니에서 손이 빠져나와 니트 목 부분을 잡아당김 | "사실 저 좋아하시죠?" → "…………." |
| **단호 / 질투** | 윗판 눌림 + 딸깍 | 팔짱 | "다음에도 그냥 저한테 물어보세요." |
| **순정** (개인 루트) | 윗판 느슨히 반개방, 크롬에 반사광 | 서류를 양손으로 꽉 쥠 | 고백 직전 |

> 공략이 진행될수록 **열린 차분의 비중을 늘린다** = 마음이 열리는 연출.

**화면 크롭**
- 스탠딩: 허리~허벅지 위까지. 다리 꼰 포즈는 잘림.
- 전신(다리 꼬고 벽 기댐): 등장 CG / 캐릭터 소개 화면 전용.
- 대사창 얼굴창: **스테이플러 머리 클로즈업** — 차분별로 윗판 각도만 바꿔 끼움.

## 7. 그림체 스펙 — 90년대 중반 PC 미연시

레퍼런스: 640×480 · 256색 시대 Windows 95 / PC-98 후기 미연시.

**디더링·채색 밀도 기준**

![[ref/그림체-디더링.webp|560]]

**화면 구성 기준** (우측 패널 → 호감도 UI, 하단 대사창)

![[ref/화면-레퍼런스-01.png|560]]

- **해상도:** 640×480 캔버스 기준으로 그리고 정수배(2×, 3×)로만 확대. 스탠딩 높이 약 400px.
- **채색:** 셀 애니메이션식 **2~3단 명암**. 부드러운 그라데이션 금지.
- **디더링:** 전체에 뿌리지 않는다. **넓은 면의 그라데이션 경계에만** 체커/베이어 2×2 패턴.
  - 스테이플러 윗판 곡면 → 하이라이트와 기본 사이 경계에 디더
  - 크롬 매거진 → 대비 강한 밴드 + 경계 디더로 금속감
  - 정장 → 주름 그림자 경계에만 약하게
- **외곽선:** 1px, 남색 띤 검정. 안쪽 선은 인접 색의 그림자색으로 (컬러 트레이스).
- **안티에일리어싱:** 거의 없음. 계단 현상이 살짝 보이는 정도가 맞다.
- **하이라이트:** 순백 픽셀을 점·짧은 선으로 찍는다 (경첩 핀, 크롬 모서리, 구두 앞코).
